# ScriptHut

Launch ScriptFlow controllers and observe workflow state, controller state and
freshness independently. ScriptFlow owns every task job. ScriptHut also offers
read-only backend job listing, repository synchronization and existing-session
terminal attachment.

Start with [installation](installation.md), [configuration](configuration/index.md)
and the [CLI](cli.md). See [ScriptFlow views and API](scriptflow.md) for server use.
